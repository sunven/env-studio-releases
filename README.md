# EnvToggle releases

This is the public download repository for EnvToggle, a macOS menu bar app for toggling shell environment variables and hosts overrides. The application source code is not hosted here.

- For a first install, or when moving from EnvToggle 0.0.2 and earlier, download the DMG from [Releases](https://github.com/sunven/env-studio-releases/releases) once the first public version is available.
- Newer public builds use Sparkle to check for updates. The ZIP and `stable.xml` are for the in-app updater.
